# CAFA 6 Protein Challenge - Vibe Configuration

## Project Context
This is a protein function prediction project for the CAFA 6 (Critical Assessment of Function Annotation) challenge. The project involves:

- Protein sequence analysis and feature extraction
- Machine learning model training for function prediction
- Dataset generation and preprocessing
- Model evaluation and optimization

## Directory Structure
- `data/` - Contains datasets and processed data
- `models/` - Saved models and checkpoints
- `env/` - Virtual environment
- `*.py` - Python scripts for data processing and training
- `*.ipynb` - Jupyter notebooks for exploration and analysis

## Tools and Dependencies
- Python 3.13+ with virtual environment in `env/`
- Biopython for protein sequence analysis
- Scikit-learn, TensorFlow/PyTorch for machine learning
- Jupyter for notebooks
- Hugging Face integration for dataset/model sharing

## Key Commands
- Activate virtual environment: `source env/bin/activate`
- Run training: `python training_run.py`
- Generate dataset: `python generate_dataset.py`

## Vibe-Specific Instructions
- Always respect the existing codebase structure
- Prefer editing existing files over creating new ones
- Use the project's virtual environment for Python operations
- Maintain compatibility with existing notebooks and scripts
- Follow the project's coding style and conventions
